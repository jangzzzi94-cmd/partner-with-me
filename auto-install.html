자동입력 북마크 (하나로 통합)

이제 북마크 하나로 보케어(보험금청구)와 ERP(고객등록) 둘 다 처리돼요. 위드파트너에서 정보를 복사하고 해당 사이트 탭을 연 뒤, 이 북마크를 탭하면 지금 보고 있는 화면이 보케어인지 ERP인지 스스로 알아채서 맞게 채워 드려요. 기기마다 딱 한 번만 설치하면 계속 써요. (예전에 보케어용·ERP용 북마크를 따로 설치해 두셨다면, 둘 다 지우고 이 북마크 하나만 남겨두셔도 돼요.)

🔒 안전하게 만들었어요

· 아이디·비밀번호는 전혀 다루지 않아요. 이미 로그인되어 있는 화면에서만 동작해요. ERP에서 로그인이 안 되어 있으면 "로그인 후 다시 눌러주세요"라고 안내만 하고 멈춰요.

· "다음" · "제출" · "청구하기" · "저장" · "삭제" 같은 되돌릴 수 없는 버튼은 어떤 경우에도 자동으로 누르지 않아요. 체크와 입력까지만 하고, 마지막 확인과 제출·저장은 항상 사람이 직접 해요.

· 북마크는 보케어(bocare.co.kr)·ERP(line.afg.kr) 두 사이트 안에서만 동작해요. 다른 사이트에서 누르면 "이 북마크는 이 두 화면에서만 동작해요"라고만 알려주고 아무 일도 하지 않아요.

📱 북마크를 눌러도 안 뜰 때 (안드로이드)

위드파트너를 홈 화면에 설치해서(앱처럼) 쓰고 계시면, "복사하고 보케어 열기"를 눌렀을 때 진짜 크롬이 아니라 주소창도 없고 북마크도 못 쓰는 미니창(위쪽에 "bocare.co.kr"만 적힌 작은 창)으로 뜰 때가 있어요. 그 상태에서는 북마크가 아예 안 보이는 게 정상이에요.

그럴 땐 그 미니창 오른쪽 위 ⋮(점 세 개)를 누르고 "Chrome 브라우저에서 열기"를 한 번 눌러주세요. 그러면 진짜 크롬 앱으로 똑같은 화면이 다시 열리고, 거기서 크롬 ⋮ → 북마크에 들어가 설치해 둔 "자동입력"을 탭하면 정상적으로 동작해요.

ERP(고객등록)는 이 문제가 안 생기도록 고쳐서, 이제 "ERP고객등록" 버튼을 누르면 바로 진짜 크롬으로 열려요. 보케어 쪽은 보험사 선택 정보가 주소에 같이 담겨가야 해서 이 방법을 그대로 쓸 수 없어, 위 방법으로 한 번만 더 눌러 주셔야 해요.

보케어보험금청구에 쓸 때

  1. 위드파트너 고객 화면에서 "📑 보험금청구" → 보험사 선택 → "복사하고 보케어 열기"
  2. 새로 열린 창에 주소창이 없고 북마크를 쓸 수 없다면, 위에 적힌 대로 ⋮ → "Chrome 브라우저에서 열기"로 한 번 바꿔주세요
  3. 진짜 크롬에서, 설치해 둔 "자동입력" 북마크를 탭 → 보험사가 자동으로 체크되고 다음 화면까지 진행돼요
  4. 화면이 더 안 넘어가고 멈춘 것 같으면, 같은 북마크를 한 번 더 탭해 주세요 (보험사에 따라 중간에 안내 화면이 끼어 한 번에 안 넘어갈 때가 있어요)
  5. 청구서 작성 화면이 뜨면 자동으로 이름·주민등록번호·연락처·직업·주소가 채워져요 (안 채워졌다면 북마크를 한 번 더 탭)
  6. 내용을 꼭 확인하고 제출은 직접 눌러주세요

ERP고객등록에 쓸 때

  1. 위드파트너 고객 화면에서 "🏢 ERP고객등록" 클릭 → 정보 복사 + ERP 탭이 열려요
  2. ERP 탭에서 설치해 둔 "자동입력" 북마크를 탭하세요
  3. 로그인이 안 되어 있으면 "로그인 후 다시 눌러주세요" 안내가 떠요 → 로그인하고 북마크를 다시 탭
  4. 고객등록 화면이 열리고 이름·주민번호·연락처·성별·고객상태·고객구분·생년월일·직업까지 자동으로 채워져요
  5. 주소는 ERP 특성상 자동 선택이 안 돼서, 검색 결과 목록에서 직접 눌러 선택해 주세요
  6. 내용을 꼭 확인하고 저장은 직접 눌러주세요
브라우저 버전에 따라 북마크 주소 편집이 막혀 있을 수 있어요. 안 되면 알려주세요 — 다른 설치 방식(Tampermonkey · Kiwi 브라우저)으로 바꿔드릴게요.
