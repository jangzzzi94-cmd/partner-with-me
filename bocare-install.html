보케어 자동입력 북마크

위드파트너 고객리스트에서 "보험금청구"를 누르면 고객 정보가 복사돼요. 보케어 화면에서 이 북마크를 한 번 탭하면, 선택한 보험사 체크와 인적사항 입력을 대신 해줘요. 기기마다 딱 한 번만 설치하면 계속 써요.

🔒 안전하게 만들었어요

· 아이디·비밀번호는 전혀 다루지 않아요. 이미 로그인되어 있는 화면에서만 동작해요.

· "다음" · "제출" · "청구하기" 같은 버튼은 어떤 경우에도 자동으로 누르지 않아요. 체크와 입력까지만 하고, 마지막 확인과 제출은 항상 사람이 직접 해요.

· 북마크는 보케어 페이지 안에서만 동작해요. 다른 사이트에서는 아무 일도 하지 않아요.

1PC (Chrome, Edge, Whale 등)

아래 버튼을 누르지 말고, 북마크바로 끌어다 놓으세요.

🔖 보케어 자동입력

북마크바가 안 보이면 Ctrl+Shift+B (맥은 Cmd+Shift+B)로 켤 수 있어요. 설치가 끝나면 끝 — 보케어에서 북마크를 탭하기만 하면 돼요.

2아이폰 (Safari)

  1. 아무 페이지에서 하단 공유 버튼 → 책갈피 추가
  2. 책갈피 목록을 열고, 방금 만든 책갈피를 편집(목록에서 책갈피를 눌러 편집 모드로)
  3. 이름을 "보케어 자동입력"으로 바꾸고, 주소 칸의 내용을 전부 지운 뒤 아래 코드를 붙여넣으세요

3안드로이드 (Chrome)

  1. 아무 페이지에서 주소창 오른쪽 ⋮ 메뉴 → 북마크 추가
  2. ⋮ 메뉴 → 북마크 → 방금 만든 북마크를 길게 눌러 수정
  3. 이름을 "보케어 자동입력"으로 바꾸고, URL 칸의 내용을 전부 지운 뒤 아래 코드를 붙여넣으세요

💡 사용하는 순서

  1. 위드파트너 고객 화면에서 "📑 보험금청구" → 보험사 선택 → "복사하고 보케어 열기"
  2. 새로 열린 보케어 탭에서, 설치해 둔 "보케어 자동입력" 북마크를 탭 → 보험사가 자동으로 체크돼요
  3. 내용 확인 후 "다음" 버튼은 직접 눌러 진행하세요
  4. 청구서 작성 화면이 뜨면, 북마크를 한 번 더 탭 → 이름·주민등록번호·연락처·직업·주소가 자동으로 채워져요
  5. 내용을 꼭 확인하고 제출은 직접 눌러주세요
브라우저 버전에 따라 북마크 주소 편집이 막혀 있을 수 있어요. 안 되면 알려주세요 — 다른 설치 방식(Tampermonkey · Kiwi 브라우저)으로 바꿔드릴게요.
