ERP 자동입력 북마크

위드파트너 고객리스트에서 "ERP고객등록"을 누르면 고객 정보가 복사되고 line.afg.kr 고객등록 화면이 열려요. 거기서 이 북마크를 한 번 탭하면, "고객등록" 화면을 열고 이름·주민번호·연락처·주소·직업을 대신 채워줘요. 기기마다 딱 한 번만 설치하면 계속 써요.

🔒 안전하게 만들었어요

· 아이디·비밀번호는 전혀 다루지 않아요. 로그인이 안 되어 있으면 "로그인 후 다시 눌러주세요"라고 안내만 하고 멈춰요.

· "저장" · "삭제" 같은 되돌릴 수 없는 버튼은 어떤 경우에도 자동으로 누르지 않아요. 입력까지만 하고, 마지막 확인과 저장은 항상 사람이 직접 해요.

· 주소는 ERP 자체 특성(카카오 우편번호 검색 위젯) 때문에 자동으로 선택할 수 없어요 — 후보 목록에서 직접 눌러 선택해 주셔야 해요.

· 북마크는 line.afg.kr 페이지 안에서만 동작해요. 다른 사이트에서는 아무 일도 하지 않아요.

1PC (Chrome, Edge, Whale 등)

아래 버튼을 누르지 말고, 북마크바로 끌어다 놓으세요.

🔖 ERP 자동입력

북마크바가 안 보이면 Ctrl+Shift+B (맥은 Cmd+Shift+B)로 켤 수 있어요. 설치가 끝나면 끝 — line.afg.kr에서 북마크를 탭하기만 하면 돼요.

2아이폰 (Safari)

  1. 아무 페이지에서 하단 공유 버튼 → 책갈피 추가
  2. 책갈피 목록을 열고, 방금 만든 책갈피를 편집(목록에서 책갈피를 눌러 편집 모드로)
  3. 이름을 "ERP 자동입력"으로 바꾸고, 주소 칸의 내용을 전부 지운 뒤 아래 코드를 붙여넣으세요

3안드로이드 (Chrome)

  1. 아무 페이지에서 주소창 오른쪽 ⋮ 메뉴 → 북마크 추가
  2. ⋮ 메뉴 → 북마크 → 방금 만든 북마크를 길게 눌러 수정
  3. 이름을 "ERP 자동입력"으로 바꾸고, URL 칸의 내용을 전부 지운 뒤 아래 코드를 붙여넣으세요

💡 사용하는 순서

  1. 위드파트너 고객 화면에서 "🏢 ERP고객등록" → "복사하고 ERP 열기"
  2. 새로 열린 line.afg.kr 탭에서, 설치해 둔 "ERP 자동입력" 북마크를 탭
  3. 로그인이 안 되어 있다면 로그인한 뒤 북마크를 한 번 더 탭하세요
  4. 고객등록 화면이 자동으로 열리고, 이름·주민등록번호·연락처·주소·직업이 자동으로 채워져요
  5. 주소는 후보 목록에서 직접 눌러 선택해 주세요 (자동 선택 불가)
  6. 내용을 꼭 확인하고 "저장"은 직접 눌러주세요
브라우저 버전에 따라 북마크 주소 편집이 막혀 있을 수 있어요. 안 되면 알려주세요 — 다른 설치 방식(Tampermonkey · Kiwi 브라우저)으로 바꿔드릴게요.
